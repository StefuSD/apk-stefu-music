# Pro

Тот же модуль, что в других приложениях Stefu (Lessons → Bot → Music). Пока
`PRO_RULES.gatesOn` в `pro.js` выключен, ничего не ограничено.

- `pro.js` — что входит в Pro: `free.snippetsDay` — 20 сниппетов в день бесплатно, с Pro — без ограничения; подписи и справка.
- `ProContext.js` — `ProProvider` (в `App.js`), `usePro()`, `useProDevTaps()`.
- `ProSheet.js` — окно Pro; `ProLock.js`, `ProWall.js` — замки; `ProRow.js` — строка в Настройках.
- `strings.js` — слова модуля, RU и EN. Один вариант покупки — навсегда.
- `billing.js` — цена, покупка и восстановление; товар `pro_lifetime`. Пока заглушка.

Где проверяется `requireRoom('snippetsDay', …)`:

- `PlayerContext` — каждая песня в режиме «Только сниппеты» берёт один сниппет из дневного объёма
  (счётчик `sm_snip_day`); сверх него режим выключается, музыка встаёт, открывается окно Pro;
- кнопки входа: Музыка → «Сниппеты», Отчёты → «Прослушать сниппеты», ссылка `snippets`.

«К сниппету» и правка сниппета в карточке песни — бесплатно всегда.

Сниппеты ищутся в фоне у всех (modules/stefu-audio) — после покупки всё уже готово.

Переключатель разработчика: 7 быстрых нажатий на строку версии в Настройках —
«Как у всех» / «Я купил Pro» / «Я бесплатный». «Я купил Pro» — только в
сборке с `EXPO_PUBLIC_PRO_DEV=1`.
